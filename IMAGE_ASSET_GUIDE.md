# MedBook AI image assets and code review

- `assets/images/previews/`: screenshots for documentation and regression review.
- `snaptext-tools/assets/images/`: `favicon.svg`, `hero-studio.svg` and tool illustration SVGs.
- The main application source is `index.html`, `app.js`, `styles.css`.

## Deliverables

1. Full project includes code and all images and is the intended runnable package.
2. Code-only archive removes all images. Use it for source-code review, but images shown on SnapText tool pages will be missing if run standalone.
3. Image-only archive contains assets under identical relative paths. You can extract it into the code-only project's root to restore imagery.

No functionality or backend data model is changed as part of this asset reorganization.
